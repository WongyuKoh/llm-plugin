# 토큰 절약 모드

## 켜고 끄기

- `/eco`, `/eco on`, 또는 토큰 절약·저비용·가볍게 진행 요청이면 켠다. `/eco off`나 끄라는 요청이면 끈다. 이번 인자: `$ARGUMENTS`
- 켠 모드는 그 세션에서 끌 때까지 유지한다. 요청이 없으면 이 기준을 적용하지 않는다.
- 켤 때 T3 도구가 있으면 `t3_thread_configure`로 현재 스레드의 모델은 유지하고 effort만 낮춘다(Claude `effort: low`, Codex `reasoningEffort: low`). 원래 값을 한 줄로 알리고 끌 때 되돌린다. 도구가 없으면 바꾸지 못했다고 알린다.

## 제한

- **탐색**: 지정된 파일과 직접 관련된 파일만 읽는다. 저장소 전체를 훑지 않고 정확한 경로와 패턴으로 찾으며, 긴 파일은 필요한 줄 범위만 읽는다.
- **도구·플러그인**: 필요한 도구만 불러온다. 출력이 큰 명령과 MCP 도구는 `head`, `grep`, `limit`, `maxCharsPerItem` 같은 제한을 걸어 실행한다.
- **위임**: 하위 에이전트, 워크플로, 병렬 위임, 새 스레드는 사용자가 요청할 때만 쓴다.
- **검증**: 변경과 관련된 테스트만 실행한다. 생략한 검증은 생략했다고 쓰고 성공했다고 추측하지 않는다.
- **응답**: 결론, 변경, 확인 결과만 짧게 쓴다. 파일 내용이나 도구 출력을 옮겨 적지 않는다.
- **중간 점검**: 변경 파일이 5개를 넘거나, 새 의존성이 필요하거나, 설계를 바꿔야 하면 계속하기 전에 범위를 알리고 묻는다.

각 스킬에 적힌 절약 모드 기준도 함께 따른다.
