# 세션 구성

`dev-flow` 스킬을 불러 "새 프로젝트 구성" 절차를 그대로 따른다. 인자: `$ARGUMENTS`

- 첫 단어가 `/`, `~`, `.`로 시작하면 대상 폴더, 나머지는 설명(주제)이다. 폴더가 없으면 현재 프로젝트를 대상으로 하고, 폴더가 디스크에 없으면 만든다.
- 설명이 있으면 세 세션을 그 주제로 묶고 범위 밖 요청을 막는다. 설명이 없으면 주제 없이 역할 범위만 정한다.
- 끝나면 세션 link, 역할, 모델, 범위를 표로 보여 준다. 같은 주제의 역할 세션이 이미 있으면 "기존"으로 표시하고 새로 만들지 않는다.
