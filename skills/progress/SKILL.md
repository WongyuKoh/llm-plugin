# 진행 상황 보기

T3 도구로 확인한 사실만 보여 주고, 다른 세션을 바꾸거나 메시지를 보내지 않는다. 인자: `$ARGUMENTS` (`all`이면 모든 프로젝트)

1. `t3_thread_list`를 `includeSubagents: true`, `limit: 20`으로 부른다. 인자가 `all`이면 `allProjects: true`를 준다. 기본 범위는 현재 프로젝트이며, 결과의 `currentThreadId`(이 세션)는 표에서 뺀다.
2. 실행·대기 중인 세션, 24시간 안에 끝나거나 실패한 세션, 아직 쓰지 않은 역할 세션(`[작업]`·`[질문]`·`[테스트]`)만 보여 준다.
3. `waiting` 상태인 세션은 `t3_pending_request`(`action: "list"`)로 사용자 질문이 있는지 확인한다. `waiting`만 보고 입력 대기라고 단정하지 않는다.
4. 실행 중, 입력 대기, 실패 세션의 최근 내용은 `t3_thread_read`(`limit: 1`, `maxCharsPerItem: 300`)로 읽는다. 최대 8개까지 읽고, 토큰 절약 모드(`eco`)에서는 질문이 있는 세션만 읽는다.
5. 아래 형식으로 보여 준다. 세션 칸에는 결과의 `link`를 그대로 쓰고, 시각은 사용자의 현지 시각으로 쓴다.

```markdown
## 📊 진행 상황 · <프로젝트> · <기준 시각>

| 세션 | 상태 | 최근 내용 | 갱신 |
|---|---|---|---|
| <link> | 🟢 실행 중 | <한 줄> | <시각> |

### ❓ 답이 필요한 질문
- <link>: <질문 요약>
```

상태 표시는 🟢 실행 중, ❓ 입력 대기, ⏳ 대기, ✅ 완료, ⚠️ 실패·중단, ⏸ 쓰지 않음을 쓴다. 질문이 없으면 질문 절을 빼고, 보여 줄 세션이 없으면 한 줄로 알린다.
