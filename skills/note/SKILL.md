# 학습 노트

`review-learning`의 "Obsidian에 학습 내용 연결" 절차를 따른다. 주제: `$ARGUMENTS` (비어 있으면 이 세션의 작업)

- vault 위치와 노트 규칙은 현재 지침(예: 프로젝트의 로컬 지침)에서 확인하고, 쓰기 전에 그 vault의 지침 문서를 읽는다. 위치를 모르면 묻는다.
- 노트는 vault에만 저장한다. 저장소 파일, 커밋, PR에는 노트 내용이나 경로를 넣지 않는다.
- 만들거나 고친 노트 경로를 알린다. 저장할 수 없으면 이유와 붙여 넣을 초안을 준다.
