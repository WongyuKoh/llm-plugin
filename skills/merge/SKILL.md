# 머지

대상: `$ARGUMENTS`. 비어 있으면 이 세션에 연결된 PR, 없으면 현재 브랜치의 PR이다.

1. PR의 체크, 리뷰, 충돌, 초안 여부를 읽는다.
2. 체크 실패나 진행 중, 변경 요청 리뷰, 충돌, 초안 중 하나라도 있으면 머지하지 않고 이유를 알린다.
3. 문제가 없으면 저장소가 허용하는 방식으로 머지한다. T3 PR 도구가 있으면 그것을 쓰고, 없으면 `gh pr merge`를 쓴다.
4. 머지 결과를 알리고, 이 세션이 감시하던 PR이면 감시를 끈다. 학습 노트가 필요하면 `/note`를 안내한다.
