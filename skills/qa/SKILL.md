# 완료 조건 검증

대상: `$ARGUMENTS`. 비어 있으면 현재 브랜치를 검증한다.

1. 완료 조건은 이 대화의 작업 카드, 없으면 PR 본문에서 찾는다. 둘 다 없으면 검증하지 않고 무엇을 기준으로 할지 묻는다.
2. 조건마다 명령이나 확인을 실제로 실행한다. 기능 코드는 고치지 않는다. 테스트 코드는 작성할 수 있다.
3. 결과를 표로 보여 준다: 조건, 결과(✅ 통과, ❌ 실패, ⏭ 실행 못 함), 근거(명령과 출력 요약).
4. 이 세션이 `[작업 요청]` 메시지로 일을 받았다면 메인 세션에 알린다. 모두 통과면 ✅ 완료, 하나라도 실패하거나 실행하지 못했으면 ⚠️ 중단이다(`dev-flow` 알림 형식).
