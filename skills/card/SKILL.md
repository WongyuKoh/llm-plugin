# 작업 카드

`$ARGUMENTS`(비어 있으면 지금까지의 대화)의 작업을 `dev-flow`의 작업 카드 형식으로 쓴다.

- 필요한 코드와 문서만 확인한다. 확인하지 못한 내용은 "위험·미확인"에 적는다.
- 완료 조건은 실행할 명령이나 확인 방법과 기대 결과로 쓴다. 정할 수 없으면 카드 끝에 질문으로 남긴다.
- 카드만 쓰고 구현은 시작하지 않는다. 넘기려면 `/handoff`를 쓴다고 한 줄로 안내한다.
